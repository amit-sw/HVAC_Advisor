How the Pieces Talk

Data flows through this app like packages through a sorting facility. Let's trace the full journey from question to answer.

Three Pipelines, One App

Each answer mode has its own pipeline — a different path the data takes from your question to the final answer. The simplest mode is a straight line; the most complex is a branching decision tree.

➡

Baseline: Straight Line

Query goes in, answer comes out. One hop: your question straight to the LLM. No documents, no climate data.

🔄

RAG: Two-Step

First search documents, then ask the LLM with the evidence attached. Two hops: vector store, then LLM.

🌳

Deep Agent: Decision Tree

The agent reads the query, decides whether to call climate first, then searches docs, then synthesizes. It chooses its own path.

Inside the RAG Pipeline

The RAG mode is the heart of this app — it's the pattern that makes AI answers trustworthy. Here's the actual code that runs it:

CODE 
def run_rag(query: str, top_k: int):
    add_trace("RAG mode started")
    retrieval = search_hvac_docs(query, top_k=top_k)
    if retrieval["results"]:
        response = rag_llm.invoke(
            rag_prompt.format_messages(
                query=query,
                evidence_text=retrieval["evidence_text"]
        ))
        answer = message_to_text(response)
    else:
        answer = "I could not ground an answer..."
    return {"answer": answer, ...}
PLAIN ENGLISH

Define the RAG pipeline — takes a question and how many docs to retrieve.

Log a breadcrumb so we can trace what happened later.

Search the HVAC document library for the most relevant chunks.

If we found any matching documents...

...send the question AND the evidence to the AI model together...

...using a pre-built template that tells the AI to only answer from the evidence...

...passing in the original question...

...and the actual document text we retrieved.

Wait for the AI to respond and extract the text.

Convert the AI's response into plain text.

But if no documents were found...

...honestly say the answer can't be grounded. No guessing!

Package everything up and return it.

The Secret Sauce: Prompt Templates

The magic isn't just in the code — it's in the instructions given to the AI. Each mode gets different rules. Compare these two system prompts:

BASELINE PROMPT 
"You are an HVAC product expert
 helping with a demo. Answer
 directly, but do not pretend to
 have access to internal documents
 or unseen product manuals."
WHAT THIS MEANS

Act like an HVAC expert...

...this is for a demonstration...

...give a straight answer...

...but don't fake having documents...

...or pretend you've read manuals you haven't.

RAG PROMPT 
"You are an HVAC product expert.
 Answer only from the retrieved
 evidence. If the evidence is
 incomplete, say so clearly. Cite
 filenames in square brackets such
 as [manual.pdf]."
WHAT THIS MEANS

Same expert role...

...but ONLY use the documents we provide. No guessing.

If the documents don't cover the question...

...say so honestly instead of making something up.

Always tell the user which document...

...each piece of information came from.

💡
Prompt Engineering is Architecture

The difference between these two prompts is the difference between a guess and a grounded answer. When you're building AI tools, the prompt is as important as the code. Telling the AI "answer only from the evidence" and "cite filenames" is what makes RAG trustworthy.

The Deep Agent Makes Its Own Decisions

Unlike Baseline and RAG which follow fixed steps, the Deep Agent reads your question and decides what to do. Here's its instruction set:

AGENT INSTRUCTIONS 
"You have two tools:
- get_climate_profile: use when
  the query includes an explicit
  location
- search_hvac_docs_tool: use for
  product facts, model comparisons

Decision rules:
- If the query includes a location,
  first call get_climate_profile
- After climate lookup, call
  search_hvac_docs_tool"
PLAIN ENGLISH

You have two tools in your toolbox:

Tool 1 — Climate lookup: use this when someone mentions a city or place...

...because the weather there affects which HVAC equipment to recommend.

 

Tool 2 — Document search: use this for any product-specific question.

 

 

Here's your decision logic:

If you spot a location in the question...

...call the climate tool FIRST to get weather context.

Then, whether or not you used climate...

...always search the docs to back up your answer.
